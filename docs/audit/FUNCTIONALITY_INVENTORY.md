# CareConnect End-to-End Functionality Inventory

This comprehensive inventory maps every feature across the CareConnect full-stack ecosystem (Django 5 + DRF backend, React 18 frontend, Razorpay gateway, Brevo SMTP, Cloudinary).

---

## Complete Feature-to-Function & Business Rules Matrix

| Feature | Layer / Page / Endpoint | Allowed Role(s) | Trigger (Button / Form / API) | Expected Business Rule & Validation Logic |
| :--- | :--- | :--- | :--- | :--- |
| **Auth: Register** | `/register`<br>`POST /api/accounts/register/` | Anonymous | "Create Account" Submit Button | Creates inactive user (`is_verified=False`), generates 6-digit cryptographic OTP, dispatches email via Brevo. Rejects duplicate emails, invalid passwords (<8 chars, missing uppercase/number). Rate limited. |
| **Auth: Verify OTP** | `/verify-otp/:email`<br>`POST /api/accounts/verify-otp/` | Anonymous | "Verify & Activate" Button | Validates 6-digit OTP code. OTP expires after 10 mins. Increments `otp_attempts`. Rejects expired/used OTPs. Marks `is_verified=True` and issues JWT access & refresh tokens. |
| **Auth: Resend OTP** | `/verify-otp/:email`<br>`POST /api/accounts/resend-otp/` | Anonymous | "Resend Code" Text Button | Invalidates older OTPs, generates new code, sends email. Throttled (max 3 resends per 15 minutes). Resets attempt counter. |
| **Auth: Cancel Registration** | `/verify-otp/:email`<br>`POST /api/accounts/cancel-registration/` | Anonymous | "Cancel Registration" Button | Deletes unverified user record and associated OTPs from DB so email can be registered anew. |
| **Auth: Login** | `/login`<br>`POST /api/accounts/login/` | Anonymous | "Sign In" Button | Authenticates via email/password. Checks account lockout (`lockout_until`). Increments `failed_login_attempts`. Locks account for 15 mins after 5 failures. Returns JWT access, refresh, role, and `must_change_password`. |
| **Auth: Logout** | Navbar / Header<br>`POST /api/accounts/logout/` | Authenticated (All) | "Sign Out" Menu Item | Blacklists refresh token in `token_blacklist` table, purges client localStorage (`access_token`, `refresh_token`, `user`). |
| **Auth: Token Refresh** | Axios Interceptor<br>`POST /api/accounts/token/refresh/` | Authenticated (All) | 401 Interceptor Dispatch | Validates JWT refresh token; issues new 15-minute access token without re-login. Rejects blacklisted refresh tokens. |
| **Auth: Forgot Password** | `/forgot-password`<br>`POST /api/accounts/forgot-password/` | Anonymous | "Send Reset Link" Button | Validates email exists; generates OTP with `purpose='reset_password'`. Dispatches Brevo email. Generic success response to prevent user enumeration. |
| **Auth: Reset Password** | `/reset-password/:email`<br>`POST /api/accounts/reset-password/` | Anonymous | "Set New Password" Button | Validates reset OTP, verifies not expired, updates user password hash, invalidates all prior sessions and OTPs. |
| **Patient: Profile View** | `/profile`<br>`GET /api/accounts/profile/` | Patient, Staff, Admin | Navigation Tab / Auto-load | Returns user profile details, total bookings count, account verification status, and avatar URL. |
| **Patient: Profile Edit** | `/profile/edit`<br>`PATCH /api/accounts/profile/` | Patient, Staff, Admin | "Save Profile" Button | Updates full name, phone number, gender, birthday, and address. Validates phone regex (10 digits). Supports avatar upload to Cloudinary. |
| **Doctors: Search & Filter** | `/`<br>`GET /api/doctors/search/` | Anonymous, Patient | Filter Dropdowns, Search Bar | Filters by specialty, hospital name, city, and date. Search matches doctor name, bio, and hospital. Returns active doctors (`is_active=True`). |
| **Doctors: Detail & Profile** | `/doctors/:id`<br>`GET /api/doctors/:id/` | Anonymous, Patient | Doctor Card Click | Returns doctor credentials, experience, qualification, base fee, hospital facility, rating, and review count. |
| **Doctors: Available Dates** | `/doctors/:id`<br>`GET /api/doctors/:id/available-dates/` | Anonymous, Patient | Date Picker / Calendar | Computes active dates over rolling 7-day window based on doctor's `available_days` schedule. Excludes blocked days. |
| **Doctors: Available Slots** | `/doctors/:id`<br>`GET /api/doctors/:id/slots/?date=...` | Anonymous, Patient | Date Selection Pill Click | Returns slots for selected date. Calculates capacity (`booked_count < 5`). Flags `is_booked_by_user` and `is_full`. |
| **Booking: Fee Calculation** | `/doctors/:id`<br>`Internal Service` | Patient | Slot Selection | Alternating pricing: 1st, 3rd, 5th bookings +5%; 2nd, 4th, 6th -5%. Rounded to whole paise (`ROUND_HALF_UP`). Deterministic. |
| **Booking: Coupon Listing** | `/doctors/:id`<br>`GET /api/appointments/available-coupons/` | Patient | Coupon Section Accordion | Evaluates user's prior booking count. Excludes already-used milestone coupons (`CouponUsage`). Returns eligible active promo codes. |
| **Booking: Coupon Validation** | `/doctors/:id`<br>`POST /api/appointments/validate-coupon/` | Patient | "Apply" Coupon Button | Validates promo code, minimum booking rules, and user usage history. Computes discount (percentage or flat) capped at `max_discount`. |
| **Booking: Slot Reservation** | `/doctors/:id`<br>`POST /api/appointments/book/` | Patient | "Confirm Booking" Button | Atomic booking with `select_for_update()` on Slot. Enforces 5-seat capacity limit. Prevents duplicate booking by same patient on same slot. Generates appointment in `pending` status. |
| **Payment: Order Creation** | `/my-appointments`<br>`POST /api/payments/create-order/:id/` | Patient | "Pay Now" Button | Creates Razorpay order in INR paise (`ROUND_HALF_UP`). Creates/updates `Payment` record in `pending` state with `razorpay_order_id`. |
| **Payment: Signature Verification** | Frontend Modal<br>`POST /api/payments/verify/` | Patient | Razorpay Handler Callback | Validates HMAC-SHA256 signature using `RAZORPAY_KEY_SECRET`. Transitions `Payment` to `paid` and `Appointment` to `confirmed`. Dispatches Brevo confirmation email. |
| **Payment: Webhook Ingestion** | `/api/payments/webhook/` | Razorpay Webhook Engine | Server-to-Server Event | Validates `X-Razorpay-Signature` against `RAZORPAY_WEBHOOK_SECRET`. Handles `payment.captured` (idempotent confirm), `payment.failed`, and `refund.processed`. |
| **Appointments: Patient List** | `/my-appointments`<br>`GET /api/appointments/my-appointments/` | Patient | "My Appointments" Tab | Lists patient's appointments categorized into Upcoming, Completed, and Cancelled. Includes doctor info, slot timing, and status pill. |
| **Appointments: Reschedule** | `/my-appointments`<br>`POST /api/appointments/reschedule/:id/` | Patient | "Reschedule" Button -> Modal | **10-Hour Rule**: Blocked with 400 error if slot is < 10 hours away. If >= 10 hours, moves appointment to new slot, decrements old slot count, increments new slot count. |
| **Appointments: Cancel & Refund** | `/my-appointments`<br>`POST /api/appointments/cancel/:id/` | Patient | "Cancel" Button -> Dialog | **4-Tier Refund Matrix**: Tier 1 (>48h): 100% refund; Tier 2 (24-48h): 75% refund; Tier 3 (2-24h): 50% refund; Tier 4 (<2h): 0% refund. Calls Razorpay refund API, records `razorpay_refund_id`, `refund_status`. Atomic lock. |
| **Appointments: Review & Rating** | `/my-appointments`<br>`POST /api/appointments/:id/review/` | Patient | "Leave Review" Button | Only permitted on `completed` appointments. Records rating (1-5) and feedback. Recalculates doctor `average_rating` and `total_ratings`. |
| **Payments: Ledger History** | `/payment-history`<br>`GET /api/payments/my-payments/` | Patient | "Payment History" Tab | Displays transaction ledger with receipt IDs, amounts, payment status pills, and digital receipt breakdown. |
| **Hospital: Queue Dashboard** | `/hospital/dashboard`<br>`GET /api/appointments/hospital/stats/` | Hospital Staff | Auto-load | Shows hospital's doctor queue for today: Patient name, token number, appointment time, and status. Real-time stats. |
| **Hospital: Patient Check-In** | `/hospital/dashboard`<br>`POST /api/appointments/:id/check-in/` | Hospital Staff | "Check In" Action Button | Transitions appointment from `confirmed` to `checked_in`. Updates queue order. |
| **Hospital: Consultation Complete** | `/hospital/dashboard`<br>`POST /api/appointments/:id/complete/` | Hospital Staff | "Mark Complete" Button | Transitions appointment from `checked_in` to `completed`. Records `completed_at` timestamp. Unlocks review submission for patient. |
| **Hospital: Emergency Slot Cancel** | `/hospital/dashboard`<br>`POST /api/appointments/hospital/slots/:id/cancel/` | Hospital Staff | "Emergency Cancel" Button | Blocks slot (`is_blocked=True`), cancels all patient bookings on that slot, issues 100% full refunds, triggers emergency patient emails. |
| **Admin: KPI Overview** | `/admin/dashboard`<br>`GET /api/appointments/admin/stats/` | Admin | Auto-load | Computes enterprise metrics: Total Patients, Total Doctors, Total Bookings, Confirmed Bookings, and Total Gross Revenue in ₹. |
| **Admin: Appointments Manager** | `/admin/dashboard`<br>`GET /api/appointments/admin/all/` | Admin | "Appointments" Tab | Lists all system appointments with search and status filters. Supports manual status override (`cancelled`, `completed`, `confirmed`). |
| **Admin: Slot Control** | `/admin/dashboard`<br>`POST /api/appointments/admin/slots/:id/toggle-block/` | Admin | "Block/Unblock" Slot Toggle | Toggles slot availability (`is_blocked`). Blocked slots cannot be viewed or reserved by patients. |
| **Admin: Doctor Management** | `/admin/doctors/add`<br>`POST /api/doctors/admin/` | Admin, Hospital | "Add Doctor" Form Submit | Creates doctor profile: specialty, qualification, experience, fee, hospital association, and photo upload. |
| **Admin: Failed Refunds Ledger** | `/admin/dashboard`<br>`GET /api/payments/admin/failed-refunds/` | Admin | "Failed Refunds" Queue | Lists payments where Razorpay refund API failed or timed out. Displays patient, appointment, amount, and gateway error message. |
| **Admin: Retry Gateway Refund** | `/admin/dashboard`<br>`POST /api/payments/admin/refunds/:id/retry/` | Admin | "Retry Refund" Button | Retries gateway refund with idempotency key. On success, updates `refund_status='processed'` and `status='refunded'`. |
